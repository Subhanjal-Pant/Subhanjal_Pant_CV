### Constrained RL for Pneumatic Height Control
*Jul 2026 – Present · targeting a Q1 journal*
- 7-state non-isothermal physics simulator (RK4, compressible orifice flow, LUT-based effective area) for a pneumatic air spring testbed with binary solenoid actuation, matched to firmware PWM logic.
- Lagrangian-constrained PPO policy in a Gymnasium environment, benchmarked against adaptive PID for tracking and disturbance rejection.
